# Duane Benedict Mahinay - Personal Portfolio

A minimal, responsive, and interactive personal portfolio showcasing my journey, projects, and skills as a Computer Engineer and Software Developer.

🌐 **Live Demo:** [duane-portfolio-next.vercel.app](https://duane-portfolio-next.vercel.app)

## 🚀 Tech Stack

- **Framework:** Next.js (React)
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion
- **Icons:** Lucide React

## 💻 Getting Started

To run this project locally on your machine:

1. Clone the repository:
   ```bash
   git clone [https://github.com/Duanemaster/duane-portfolio-next.git](https://github.com/Duanemaster/duane-portfolio-next.git)
   ```
